# 代码入口与边界

项目使用原生 HTML/CSS/JavaScript、Manifest V3 和 esbuild；没有应用框架或服务端。发布包的脚本由本地依赖打包，不从 CDN 加载。

| 能力 | 入口 | 主要依赖与职责 |
| --- | --- | --- |
| 独立文本页 | `src/app.js`、`src/index.html` | `controller.js` 管理请求时序；`workspace.js` 管理当前页恢复；`terms.js` 整理词义；`dictionary.js` 查询补充 |
| 工具栏菜单 | `src/popup.js` | 网页开关、范围和语言；`public/tabs.js` 复用独立翻译标签页 |
| 网页与划词 | `src/content.js` | `page-segments.js` 提取；`page-queue.js` 调度；`page-translation.js` 插入/恢复；`selection-chat.js` 对话；`page.css` 隔离样式 |
| 后台 | `src/background.js` | 验证发送者与消息参数，读取凭据，发起翻译与流式 AI，绑定取消和页面归属 |
| 翻译协议 | `src/providers.js` | 七个翻译服务、错误分类和参数约束；`page-protocol.js` 暴露安全设置与消息契约 |
| 翻译配置 | `src/settings.js` | 提取已编辑字段、增量合并；协调扩展页和后台的配置写入 |
| AI | `src/llm-service.js` | AI SDK 的协议 provider、上下文约束、流式文本与安全错误 |
| 声音 | `src/unified-speech.js` | 统一系统声音与云端控制；`speech.js` 选择本地声音；`cloud-speech-worker.js` 绑定页面任务 |
| 云端播放器 | `src/offscreen.js`、`src/audio-player.js` | 合成、分段、下一段预取、暂停恢复、取消隔离、Blob 释放；`tts-service.js` 调用 SDK/适配器 |
| 配置页 | `src/services.js`、`src/assistant-config.js` | 模型/声音预设、用户覆盖、公开设置、测试连接及试听 |
| 请求边界 | `src/service-fetch.js` | 配置地址校验、同源限制、禁止重定向/Cookie、响应体积限制、错误脱敏 |

`translation-settings-v1` 与 `selection-services-v1` 独立保存；扩展网页、后台与 offscreen 是可信上下文，普通网页脚本不获得 Key。新增协议时沿用这个边界，不让网页消息携带凭据或覆盖服务地址。

翻译配置统一通过 `updateSettings(patch)` 保存。扩展页与后台使用同名 [Web Lock](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API)，在锁内读取最新配置、合并本次修改并写入；不要在调用方先读取完整快照再回写。配置结构和存储键保持兼容。凭据表单使用 `providerChanges()` 提取实际编辑字段，保留其他页面已修改的 Key、模型及网页偏好；保存凭据不会切换当前翻译标签页使用的服务。

普通翻译页直接调用翻译模块；网页脚本通过后台消息调用。云端音频由 offscreen 持有，后台只保存任务归属。用户取消、换选区、关闭页面或启动新任务后，旧请求和音频回调都不能操作新任务。

AI 回复完成后才将 Markdown 经过 DOMPurify 渲染；流式阶段按文字展示。不得把模型 HTML、图片或嵌入对象直接插入网页。网页译文由隔离节点插入，不替换原有 DOM；关闭时只移除插件创建的节点。

`content.js` 监听原生 [Navigation.currententrychange](https://developer.mozilla.org/en-US/docs/Web/API/Navigation/currententrychange_event)，覆盖 History API 与浏览器前进后退，不覆写网站路由函数。路径、查询参数或非锚点片段变更后复用现有停止/取消逻辑，并清空页面翻译缓存；同 URL 状态更新和可解析目录锚点保留当前会话。页面地址仅在内容脚本内比较，不传给服务商，也不新增权限。

动态内容由 `PageTranslation.changedAt` 按正文块记录变更时间，块归属与提取共用 `PAGE_BLOCKS`。每块独立等待 100ms 稳定，不把其他块的变化当成重置条件；没有稳定块时只检查待处理时间，有稳定块才扫描页面。仍变动的块推迟排队，之后稳定时重新检查视口再发送。停止或换页清理待处理时间与定时器；不改独立输入页的即时翻译。

变更观察器同时撤下受影响记录的待发送分块；移除子树和改变排除属性时包含后代正文块。扫描对账也会撤下消失或替换的记录。`PageQueue.discard(ids)` 只移除等待项并释放其去重标记，允许稳定后重新排队；已发送批次继续完成，不宣称能撤回服务端请求。

## 验证入口

- `npm run check`：Node 单元测试和实际打包构建，覆盖协议、语言、并发、配置、音频及发布包限制。
- `npm run test:browser`：隔离 Chromium 扩展测试，复用 `scripts/browser-*-smoke.mjs` 中导出的场景，覆盖网页与划词、配置保存、音频、严格 CSP、键盘及正文验证边界。`tests/browser/fixture-server.js` 提供随机本机端口及测试音，不需要真实账号。
- `TRANSLATE_LIVE_MICROSOFT=1`：显式启用公共文档与真实微软接口检查，不属于默认 CI；运行命令见贡献指南，结果不能混作受控响应验证。
- 真实供应商脚本：保留在 `scripts/`，需额外凭据和费用许可，结果与 CI 分开记录在 [验证记录](验证记录.md)。
- `npm run package`：检查并构建后，按白名单生成 ZIP 和 SHA-256。运行方式见 [发布说明](发布说明.md)。
