# 免费模型说明

核查日期：2026-10-09。插件新增三个服务入口，默认微软免 Key 翻译仍可直接使用。新增服务都需要用户自己注册账号、取得 Key；插件不提供共享 Key，也不自动切换厂商。

## 选择了什么

| 服务与模型 | 免费条件 | 选择依据 | 插件能力 |
| --- | --- | --- | --- |
| 智谱 `glm-4.7-flash` | 智谱官方宣布免费 API 调用，仍受账号权限与限流约束 | 官方推荐用于翻译等通用任务，支持关闭深度思考 | 文本翻译、短词候选与双语例句 |
| 硅基流动 `tencent/Hunyuan-MT-7B` | 当前价格表的输入、输出均标为免费，仍需 Key | 腾讯的专用翻译模型；官方提供翻译评测及推荐提示词 | 单份主译文，保留复制和系统朗读 |
| Google `gemini-3.1-flash-lite` | Gemini Developer API 免费层有配额与地区限制；付费项目可产生费用 | 官方列出翻译用途，适合高频、低延迟任务 | 文本翻译、短词候选与双语例句 |

这次选择依据是官方模型能力、免费政策和接口适配成本。**未使用这三家的有效 Key 做翻译质量对比，因此没有实测排名。** 不把注册赠送余额、限时试用或聊天网页免费等同于免费 API。

为避免误选付费模型，这三个入口固定使用上述模型，设置中只显示 Key。智谱使用普通开放平台 Key，不使用 GLM Coding Plan Key。硅基流动调用其中国站接口，不使用腾讯云 Key。Gemini 使用 Google AI Studio 的 Developer API Key，不使用 Vertex AI 凭据。

## 获取 Key 和使用

1. 打开插件右上角「设置」，选择需要配置的服务。
2. 点击服务提供的链接：智谱 [API Key 管理](https://bigmodel.cn/usercenter/proj-mgmt/apikeys)、硅基流动 [API Key 管理](https://cloud.siliconflow.cn/account/ak)、Google [AI Studio](https://aistudio.google.com/apikey)。
3. 在厂商平台完成账号注册及所需认证，取得自己的 Key。
4. 将 Key 填入插件，点击「测试连接」。成功后保存配置，在主界面切换到该服务。

Key 仅保存在当前浏览器的扩展本地存储中。不要把 Key 写入源码、README、截图或 Issue。测试连接发送一次“Hello”翻译请求，会使用对应账号额度。

免费模型也可能限流或下线。遇到错误时，插件提示检查配置或稍后重试；不会静默转用付费模型。Gemini 是否免费由对应项目的计费状态决定，插件无法查询该状态。Google 的免费层内容可能用于改进产品，翻译敏感资料前应查看其数据条款。Google 还要求所在地区受支持，见 [地区列表](https://ai.google.dev/gemini-api/docs/available-regions)。

## 接口与来源

| 服务 | 固定接口 | 特殊处理 |
| --- | --- | --- |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `thinking.type = disabled`，减少翻译等待 |
| 硅基流动 | `https://api.siliconflow.cn/v1/chat/completions` | 使用混元翻译的推荐模板，不索取词典 JSON |
| Gemini | `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` | 使用官方兼容接口，`reasoning_effort = minimal` |

请求使用 HTTPS 和 `Authorization: Bearer <用户自己的 Key>`，不经过本项目的服务器。原文仅发送给当前选择的服务。插件不自动充值，也不启用厂商计费。
