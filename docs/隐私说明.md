# 数据与权限

本说明描述当前源码的数据流，服务商如何处理收到的数据由其账号条款决定。项目没有自建中转服务、账号、翻译历史库、广告或统计 SDK。

| 操作 | 发送什么 | 发给谁 | 触发时机 |
| --- | --- | --- | --- |
| 独立文本翻译 | 输入文字、语言和翻译指令；模型翻译可能含词义/例句格式要求 | 当前翻译服务 | 输入完成或粘贴后立即触发，输入法组合期间不触发 |
| 网页双语 | 当前范围内待翻译的文字段落和目标语言 | 当前翻译服务 | 用户主动开启后，随视口与动态内容继续处理 |
| 划词翻译 | 选中文字及目标语言 | 当前翻译服务 | 点击翻译或右键翻译 |
| 中英短词补充 | 查询词 | 必应词典（微软服务时） | 翻译符合条件的短词时 |
| 问问 AI | 选中文字、用户问题、当前面板的上下文与回答偏好 | 用户所选 LLM 地址 | 用户主动发送问题或点击建议问题 |
| 云端朗读 | 待读文字、语言、音色、模型和语速 | 用户所选 TTS 地址 | 点击朗读或试听；长文字最多预取下一段 |
| 系统朗读 | 文字交给浏览器的本地系统声音 | 本设备 | 点击朗读；只选择标记为本地的声音 |

请求不附带网页 Cookie、网页 URL 或整份 HTML。API Key 随对应服务的认证请求发送。自定义接口由用户配置；远程接口要求 HTTPS，本机 loopback 接口可用 HTTP。请求禁止重定向，不在失败时静默改用另一家服务。取消请求不保证服务商停止计算或计费。

网页翻译的开启只作用于当前页面。单页网站切换路径、查询参数或非锚点哈希路由时停止翻译、关闭划词场景并清理该页翻译缓存，需再次主动开启。当前文档已有的目录锚点与同 URL 历史状态更新不视为切换页面；同 URL 内动态增加的正文仍会处理。地址仅在网页本地比较，不加入翻译请求。

## 本地保存

- **Key 与偏好**：`chrome.storage.local`，不通过 `chrome.storage.sync` 同步。读取权限限制为扩展可信上下文。此存储不是操作系统密码保险箱，也不应被当作加密备份；能访问浏览器配置的本机用户或恶意程序仍可能读取。
- **网页脚本**：只收到服务名称、是否配置及非敏感偏好，不能读取 Key；网页翻译请求由后台发出。TTS 在可信 offscreen 文档中合成和播放，音频 Blob URL 随任务结束或取消释放。
- **独立翻译页会话**：原文、服务、目标语言与结果暂存于该标签页的 `sessionStorage`，不含 Key。浏览器恢复标签页可能恢复该会话。清空内容后保留 8 秒撤销机会。
- **网页译文与 AI 上下文**：只保存在当前页面内存。AI 面板关闭后清除对话；页面刷新或关闭后移除内存缓存。
- **音频任务归属**：`chrome.storage.session` 保存任务 ID 和页面归属，用于后台重启后的正确停止，不保存音频、Key、原文或模型配置。
- **网页预览**：Key 仅在当前页面内存，刷新清除。安装后的扩展使用上面的本地配置方式。

## 为什么需要这些权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存用户配置及音频任务归属 |
| `contextMenus` | 提供网页翻译和选中文字翻译入口 |
| `offscreen` | 在网页 CSP 之外管理云端语音的 Blob 与播放生命周期 |
| 普通 HTTP/HTTPS 网页访问 | 显示操作条、提取待翻译文本、插入译文；连接用户配置的服务 |

不请求 `tabs`、剪贴板读取、麦克风或浏览记录权限。文字可用系统选中复制；复制按钮只写入剪贴板。没有默认的全站自动翻译：每次跳转或刷新后需再次主动开启。
